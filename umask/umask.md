## view current umask
TO change the default permission of a folder and file <br>
```bash
umask
```
## view current umask symbolically
```bash
umask -s
```
## Permanent change for all users & perticular user
**Note:** *For all user edit `/etc/bashrc`, for particular user `.bashrc` of users profile* <br>
```bash
source .bashrc //bashrc editing to take effect
```
